# Plugin wordmarks: sources and licences

Every built-in plugin's text logo (J-130, "Tile"): `<id>.svg` belongs to plugin type `gl.<id>`,
`_suite.svg` and `_suite-mini.svg` are the Gridline Suite and Gridline Suite Mini logos. They are
generated by `tools/wordmarks/make_wordmarks.py` (do not edit them by hand), embedded at build
time by `cmake/EmbedWordmarks.cmake` and drawn by `src/app/icons/Wordmark.cpp`.

- The tile, its pictograms (`tools/wordmarks/motifs.py`) and the Tile mark are Gridline originals
  (GPL-3.0, like the rest of Gridline).
- The lettering is made of glyph outlines of Inter Bold (`assets/fonts/Inter-Bold.ttf`,
  SIL Open Font License 1.1, `assets/fonts/Inter-LICENSE.txt`), set in the Gridline logo guide's
  lockup proportions. Only outlines are drawn into the logos; no font software is included here.

Shape ids carry colour roles (`mark`, `cut`, `word`, `dim`): the app tints them from the theme.
Adding a plugin: add a row to `tools/wordmarks/plugins.py` and run the script; the
`j130_wordmarks` test fails while a catalogue plugin has no wordmark.
