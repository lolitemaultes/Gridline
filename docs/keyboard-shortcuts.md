# Keyboard shortcuts

**Settings > Shortcuts** lists every command with its keys. Search by a command's name or by its
keys, pick which window's commands to show, and use **Change**, **Add**, **Clear** and **Default**
on a row. **Help > Keyboard shortcuts** (F1) shows the same list to read.

The **Shortcut set** at the top picks which default shortcuts apply. Each window layout has its own
set, and your changes are kept for each set.

## My keys say

Beside the shortcut set, **My keys say** asks what is printed on your keys: **Same as my
computer** (the default), **QWERTY**, **QWERTZ**, **AZERTY**, **Dvorak** or **Colemak**.

Every name of a key in Gridline then follows what is printed on the key that runs it: the menus,
hints, tooltips and status lines, Settings > Shortcuts (the list, the side panel, the messages and
the search), Help > Keyboard shortcuts, the Tracker help's key lists, the command palette and the
typing keyboard's note keys. When you press a new shortcut under **Change** or **Add**, it is shown
by its printed key too. A tooltip or hint that names a shortcut names the key that runs it in the
shortcut set in use (the metronome button says **O** in Clips), the key you gave it in
Settings > Shortcuts, or **no key** when you took its keys away.

A plugin's own editor keeps its own texts: a key named inside a built-in plugin's window is not
renamed.

No shortcut moves: only the names change. For example, if your computer types Dvorak on a keyboard
printed QWERTY, choose **QWERTY**: Stop all sound shows as **Ctrl+J** and Copy as **Ctrl+I**, the
keys you actually press.

With **Same as my computer** every name is as it always was: letters and digits are named by what
your computer types.

## Punctuation keys

Shortcuts on letters, digits and **,** **.** **;** follow what your computer's layout types. The
other punctuation keys (**-** **=** **[** **]** **\\** **'** **/** **`**) follow where the key sits on
a US keyboard, so they stay put on most layouts.

On a layout where that would leave one of them with no key at all (US Dvorak has no **/** key that
way), the punctuation keys follow what they type instead, as the letters do, so every shortcut can
still be pressed. On US QWERTY, QWERTZ, AZERTY and Colemak nothing changes. If a shortcut still has
no key on your layout, its name says **(no key)**: give it another key in Settings > Shortcuts.

Typing in a text field is never affected.
