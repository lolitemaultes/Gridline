Gridline 0.6.1 answers everything reported in the first issue on GitHub, checks every control of every built-in plugin, and brings a new plugin. The interface now opens at the right size on Linux laptops, the flagship plugins have names of their own, the major effect editors are sharper, and Tideline pumps the mix on the beat. Projects, presets and FL Studio files from 0.6.0 open unchanged.

## Highlights

### Fixes from issue #1

- **The right size on Linux.** Gridline used to work out its interface size from the screen's physical pixel density, so a 1920x1080 laptop set to 100% opened at 150%, plugins included. It now follows your desktop's own scale setting. A new option, **Settings, Interface, Follow the system's display scale**, can be turned off to choose the size yourself.
- **Auto Pan pad.** The live dot used the wrong volume scale and could sit outside the pad. It now stays inside the pad and follows the pointer, with the ring showing your setting and the dot showing where the LFO moves it.
- **Windows dragged to the top** stop under the top bar in one piece, with no empty band above their content.
- **Space in a plugin's own window.** On Linux, Space, F1 to F12 and Ctrl or Alt shortcuts now reach Gridline while a hosted plugin's window has focus.
- **Play, stop and record** react as soon as you press them.
- **A metronome that swings.** With the metronome on, its icon swings on every beat while the song plays. A new **Interface animations** switch in **Settings, Interface, Motion** turns this and the other decorative animations off, and follows your system's reduced motion setting.

### Tideline: pump the mix on the beat

A new rhythmic volume ducker. One big Amount dial, 16 curves for pumping, sub bass, kick trimming, reverse swells and rhythm, plus a curve you draw yourself. It follows the tempo, or a kick on another track through sidechain routing, or MIDI notes, in loop or one-shot mode. Rates run from 1/16 to 2 bars with triplets and dotted values; it can duck only the lows or highs, or only the mid or side, and it adds no latency. Search the plugin picker for "sidechain", "pump" or "ducking" to find it.

All 136 built-in plugins and about 13,000 settings were tested for an audible effect, correct wiring in the editor, automation and saving. ## Downloads for every platform

Installers, disk images, packages and archives for Windows (x64 and ARM64), macOS (one universal app for Apple Silicon and Intel), Linux (x86_64 and aarch64, as AppImage, `.deb`, `.rpm` and `.tar.gz`) and the three BSDs. Each file is listed below with a SHA-256 checksum. Project files, presets and settings are the same everywhere, so a song started on one computer opens on any other.

### Pitch and time stretching, rebuilt

A new stretch engine (Signalsmith Stretch, MIT) with a band-limited sinc resampler for pitch. Pitch shifts land within a hundredth of a cent, drum hits stay sharp, the level no longer flutters and pitching up no longer aliases. It drives playlist audio clips, the sampler, the slicers, the audio editor and the pitch shifter, which gains a Hi-fi engine. Five stretch modes (Resample, Auto, Mono / vocal, Transient, Formant keep) are picked per clip or per channel.

Volume and pan knobs, the mute light and the mixer track stay in place however long the pattern is. On a narrow rack or mixer the mouse wheel scrolls instead of nudging a control.

Effect editors draw live graphics while the song plays: the reverb shows its room in 3D (drag it up or down to change the room size) with the decay curve under it, the delay draws its saturation curve, and the limiter plots the level against its ceiling.

Gridline looks for a newer release on GitHub at most once a day and offers to download it, remind you later or skip that version. It sends nothing about you or your projects, and it can be turned off in **Settings, General**. **Help, Check for updates** checks right away.

## Install notes

### macOS

1. Open the `.dmg` and drag **Gridline** onto **Applications**. The app is universal: it runs natively on Apple Silicon and Intel Macs.
2. The build is not notarized by Apple. The first time, right-click (or Control-click) Gridline in Applications, choose **Open**, then **Open** again. You can also allow it in **System Settings, Privacy & Security** with **Open Anyway**. If macOS says the app is damaged, run once in Terminal:
   ```sh
   xattr -dr com.apple.quarantine /Applications/Gridline.app
   ```
3. Plugins (optional): the `Plugins` folder in the disk image holds Gridline as a plugin for other hosts. Copy them to your user plugin folders and clear the quarantine flag the same way:
   - `Gridline.vst3` to `~/Library/Audio/Plug-Ins/VST3`
   - `Gridline.clap` to `~/Library/Audio/Plug-Ins/CLAP`
   - `Gridline.component` to `~/Library/Audio/Plug-Ins/Components` (Audio Unit)
4. The command line tool `gridline` is in the disk image too; copy it somewhere on your `PATH`, such as `/usr/local/bin`.

### Windows

1. **Installer** (`-setup.exe`): installs Gridline in `Program Files` (it asks for administrator rights), with optional plugins (VST3 and CLAP into `Common Files`), project file types and a desktop icon. **Zip**: extract anywhere and run `gridline-app.exe`; keep the `assets` folder next to it.
2. The builds are not code signed. If SmartScreen shows "Windows protected your PC", choose **More info**, then **Run anyway**.
3. Plugins from the zip (optional): copy `plugins\VST3\Gridline.vst3` to `C:\Program Files\Common Files\VST3`, and `plugins\CLAP\Gridline.clap` with `plugins\CLAP\Gridline-assets` to `C:\Program Files\Common Files\CLAP`.
4. Use the ARM64 files on Windows on ARM computers; the x64 files on everything else.

### Linux

- **AppImage:**
  ```sh
  chmod +x Gridline-0.6.1-linux-x86_64.AppImage
  ./Gridline-0.6.1-linux-x86_64.AppImage
  ```
- **Debian, Ubuntu:**
  ```sh
  sudo apt install ./Gridline-0.6.1-linux-amd64.deb
  ```
- **Fedora, openSUSE:**
  ```sh
  sudo dnf install ./Gridline-0.6.1-linux-x86_64.rpm      # or: sudo zypper install ./Gridline-0.6.1-linux-x86_64.rpm
  ```
- **tar.gz:** extract anywhere (or into `/usr/local`) and run `bin/gridline-app`. It needs the system's SDL2 and ALSA libraries (JACK is optional).
- The packages install Gridline as a plugin in `/usr/lib/vst3` and `/usr/lib/clap`; from the tar.gz, copy `lib/vst3/Gridline.vst3` to `~/.vst3` and `lib/clap/Gridline.clap` to `~/.clap`.
- **Wayland:** Gridline runs natively through SDL. The interfaces of hosted third-party plugins are X11 windows and open through XWayland, which most desktops start on their own.
- On aarch64 use the files with `aarch64` or `arm64` in their name.

### FreeBSD, OpenBSD, NetBSD

Extract the archive and run `bin/gridline-app` (the command line tool is `bin/gridline`). Install the libraries it needs first:

| System | Packages |
|---|---|
| FreeBSD | `pkg install sdl2 sndio libX11 mesa-libs` |
| OpenBSD | `pkg_add sdl2` (X11, Mesa and sndio are part of the base system) |
| NetBSD | `pkgin install SDL2 sndio` (with the X11 sets installed) |

Audio goes through SDL (sndio or OSS), MIDI devices through sndio, and plugin interfaces open on X11.

## What's new in 0.6.1

### Fixes from issue #1

- Linux and BSD: the automatic interface scale now follows the desktop's scale setting (Xft.dpi,
  GDK_SCALE, Qt and Wayland scaling) instead of the panel's physical pixel density, so a 1920x1080
  laptop at 100% opens at 100%. A new option, Settings > Interface "Follow the system's display
  scale", can be turned off to set the size yourself.
- Auto Pan: the pad's live dot used the wrong volume scale and could sit outside the pad. The dot and
  the setting ring now share one mapping, stay inside the pad and follow the pointer. The X-Y Pad
  output dot is clamped the same way.
- Floating windows dragged against the top no longer leave an empty band above their content.
- Linux: Space, F1 to F12 and Ctrl/Alt shortcuts reach Gridline while a hosted plugin's own window
  has focus. Windows uses the same rule.
- The play, stop and record buttons act on press.
- The metronome icon swings on every beat while the metronome is on and the song plays. A new
  "Interface animations" switch (Settings > Interface > Motion) turns decorative animations off and
  follows the system's reduced motion setting.

### Plugin editors

- One shared knob renderer for every built-in editor: anti-aliased rings, hover glow, shaded caps.
- Refined section headers, recessed value fields, gradient graph fills and hover readouts on the
  filter, maximizer, band delay and envelope editors.
- Shuttle: time and volume colour coding, cleaner slot cells and a readout while dragging a point.

### Every parameter checked

- New `gridline param-audit` command and test: every parameter of every built-in plugin is checked
  for an audible effect, engine use, editor wiring, automation and save/load.
- Bitcrusher: Downsample now defaults to 1, so the Bits control is audible all the way to 24 bits
  (the old /4 default masked every depth above about 6). The 8-bit preset keeps its /4.
- Fixed crashes or runaway output in Crest, Enhance, Lattice ring-mod loops, Octa Filter ALT
  resonance, and Isoline when an oscillator was switched on during playback.
- Wired parameters the engines ignored: pitch bend range (Hybrid, DCO and Hex synths), Hex Synth
  modulation sources, Pocket Synth mod wheel, MIDI Out bend range and pass-through, Spectra Morph
  chorus rate, Grain Scanner volume and transient hold, Kerf minimum slice gap, Pitch Shifter Hi-fi
  tempo sync, Alloy and Halftone chorus, Pixel Tone rows, Pedal Rack boost and more.
- Saw Swarm and Twin VA glide fixes; Note Sequencer ties hold their note.
- Missing editor controls added (Facet fine tune, Folio program controls); percentage readouts that
  showed values like "10000%" fixed.
- Abacus and the sampler no longer misbehave when a sample's start is set to its very end; the
  same kind of fix for the slicer's slice ends, plugin event timing and a few editor labels.

### New plugin

- New effect: Tideline (`gl.tideline`, Dynamics). It is a rhythmic volume ducker with one big Amount
  dial, 16 pump, sub, trim, reverse and rhythm curves plus a drawable curve, and rates from 1/16
  to 2 bars (triplet and dotted included). It can follow the tempo or be triggered by audio (track
  sidechain) or MIDI, in loop or one-shot mode with an end marker. Duration and shift are
  adjustable, it can duck only the lows or highs, or only the mid or side, and it adds no latency.
  It exports to FL Studio as a Gross Beat volume envelope. See `docs/plugins/tideline.md`.

## FL Studio project compatibility

Gridline reads and writes FL Studio project files so existing work can move in both directions:

- **Import:** all 164 demo projects that ship with FL Studio import without errors and with an exact structure (channels, patterns, notes, playlist, automation, markers, mixer routing and plugin settings), and play back with their sound.
- **Export:** projects saved as `.flp` or as an FL Studio zipped loop package open in FL Studio 2026. Unchanged parts of an imported project are written back exactly as they were read.
- **Gridline-only plugins** are written as stand-ins so the exported song still sounds right: close FL Studio equivalents where one exists, otherwise the part is rendered to audio and played by a sampler.
- Third-party plugins load as the installed plugin with their saved state, or stay as placeholders until it is installed.

Gridline is an independent project and is not affiliated with or endorsed by Image-Line. "FL Studio" is a trademark of Image-Line Software and is mentioned only to describe file compatibility.

## Known limitations

- **Unsigned builds:** the macOS app is not notarized and the Windows files are not code signed, so the first start needs the steps above.
- **Plugin editors outside macOS:** the native interfaces of hosted plugins on Windows, Linux and the BSDs are built and tested automatically, but have not yet been tried by hand.
- **Sandboxed plugins on Windows** play and save normally, but their editor window is a placeholder for now; open the plugin outside the sandbox to see its interface.
- **Windows on ARM64** is built on every change but its tests do not run in CI yet.
- **Wayland:** plugin interfaces open through XWayland, not as native Wayland windows.
- **Halftone and Alloy:** about 75 advanced settings (some filters, strum, reverb and delay options) are listed but not built yet; they are marked as such and do nothing for now.
- **Linux transport buttons:** play, stop and record now react on press. If they still miss clicks on your desktop, please tell us in an issue whether your session runs X11 or Wayland.

## Checksums

`Gridline-0.6.1-SHA256SUMS` lists the SHA-256 checksum of every file. Put it in the same folder as your download and run:

```sh
# Linux, BSD
sha256sum --ignore-missing -c Gridline-0.6.1-SHA256SUMS
# macOS
shasum -a 256 --ignore-missing -c Gridline-0.6.1-SHA256SUMS
```

On Windows (PowerShell), compare the output with the line for your file:

```powershell
Get-FileHash .\Gridline-0.6.1-windows-x64-setup.exe -Algorithm SHA256
```

On FreeBSD and OpenBSD, `sha256 Gridline-0.6.1-freebsd-x86_64.tar.gz` prints the checksum to compare.
