**Gridline 0.7.0 beta 2 is a beta.** It is published as a GitHub Pre-release, so Gridline's update check only offers it to people who turn on **Include beta versions** in **Settings, General, Updates**. Anyone can download it from this page, and 0.7.0 itself follows later. Projects from 0.6.1 and beta 1 open as they are: the project format has not changed. If something does not work as it should, please [open an issue on GitHub](https://github.com/lolitemaultes/Gridline/issues); every report helps get 0.7.0 ready.

Beta 2 builds on beta 1's live collaboration and refined interface. Gridline's own instruments and effects now run in any DAW as the **Gridline Suite**, with **Gridline Suite Mini** beside it. The interface gets **five control styles** with Slate as the new default, plus **sound themes**. Swing is now **smooth**, and there is a new **demo song**, "Gridline". Collaborative projects need everyone on the same version, so for this beta everyone in a session runs 0.7.0 beta 2.

## Highlights

### Gridline's plugins in any DAW

Every download carries the **Gridline Suite**: Gridline's instruments and effects, each a plugin of its own for other hosts, as VST3, CLAP and (on macOS) Audio Unit. Each plugin is the same sound and the same editor as inside Gridline, with named, automatable parameters, the factory presets, sidechain inputs where the effect uses one, and a state that moves between Gridline and another host unchanged.

**Gridline Suite Mini** adds 35 compact single-purpose effects in the same formats: tone, dynamics, drive, pitch, motion, time and utility, each with one clear job and a small editor. A project that uses one of the Kilohearts single effects that is not installed opens with its Mini counterpart in the slot. The original plugin and its settings stay in the project, so it is hosted again on a computer that has it.

The Windows installer and the Linux packages put both suites where hosts find them. On macOS, with the AppImage and with the `.tar.gz` builds, Gridline asks on first launch whether to copy them into your plug-in folders. See `docs/gridline-suite.md`.

### Your look, your sounds

**Settings, Theme** brings everything about the interface's look and sound together in one place.

- **Control styles** change how knobs, faders, buttons, meters and displays are drawn everywhere, without moving anything:
  - **Slate**, the new default: a quiet studio slate.
  - **Graphite**: machined and lit.
  - **Hairline**: flat lines with one accent.
  - **Lumen**: dark glass, with values shown as light.
  - **Classic**: the earlier look.
- **Light and dark themes**, your own accent, and colours for lit glyphs, LEDs and the song position.
- **Sound themes** for the interface sounds (start-up, save, export, record and the rest). Graphite is the default, and you can preview each theme before you choose it.

Every built-in plugin now shows its own wordmark, in its window header and in its own editor.

### Swing that feels right

- **Smooth at every setting.** Swung steps and notes are now placed between ticks and played to the sample, so every percent of the swing knob is heard. Before, small amounts did nothing and the knob moved in coarse jumps.
- **Notes swing too.** Song swing now moves piano roll notes as well as channel rack steps. In each pair of steps, the off-beat moves later and everything between moves in proportion, so 32nds and triplets bend with the groove instead of jumping. Notes keep their written positions in the piano roll; only playback swings.
- **Note Sequencer and Arpeggiator stay on the song grid**, even for a key pressed a little late. The Note Sequencer's step velocity can now scale how hard you play.
- **Drum and plugin sequencers fixed.** Drum sequencers no longer drift, Plasma's arpeggiator swings on the grid, and its clip player no longer skips notes.

### A new demo song

The new demo song, "Gridline", is a 4:25 atmospheric liquid drum & bass track at 174 BPM, made only with Gridline's own instruments, effects and automation: no samples. It opens by itself once, on the first launch of a new install, and any time from **Help, Load demo song**. It is a full project to take apart:

- the felted wooden mallet lead, built from the Graphite interface sound;
- the moving reese over a mono sub;
- a synthesised rain bed;
- buses, sidechains and automation shaping every section.

### Smaller changes

- **Knobs:**
  - double-click resets a knob to its default, or opens the value box when it is already there;
  - the right-click menu starts with **Reset to default**;
  - this works in every built-in plugin, the mixer and the channel rack.
- **Fader caps** sit exactly on their tracks in every style and at every interface scale.
- **No more cut-off outlines.** Selection outlines, the playing step and focus rings are no longer cut off at the edge of their panel.
- **Playlist song markers** are quieter: each marker's tick is now the left edge of its label.
- **Installers:** the macOS disk image and the Windows setup are in Gridline's design, and the Linux packages carry AppStream metadata for software centres.

The full list is in [CHANGELOG.md](https://github.com/lolitemaultes/Gridline/blob/v0.7.0-beta.2/CHANGELOG.md).

## Install

Install steps are the same as for beta 1:

- **macOS:** open the `.dmg` and drag Gridline to Applications. The first time, open it with right-click, then Open.
- **Windows:** run the `-setup.exe`. If SmartScreen appears, choose "More info", then "Run anyway".
- **Linux:** use the `.AppImage`, `.deb`, `.rpm` or `.tar.gz`.
- **BSDs:** use the `.tar.gz` for your system.

Every file's checksum is in `Gridline-0.7.0-beta.2-SHA256SUMS`.
