Gridline 0.7.3 is a point release on top of 0.7.2, mostly about staying up and staying responsive. **Crashes and freezes now explain themselves and offer your project back**, **big and zipped projects on slow drives open properly**, **long saves and exports no longer freeze the window**, **large projects play more smoothly**, and FL Studio projects import more of their settings, including tempo automation. **Clips and notes placed off the grid now stay where you put them**, **Track Receipt works out each song's share**, and there is a **tap tempo button** in the top bar.

## Highlights

### Crash reports and project recovery

If Gridline crashes or freezes, a window now says what happened and gives you a code to copy. The code holds the version, system, graphics card, the failing thread and functions, and your last few actions. It holds no file paths and no project names, and Gridline never sends it anywhere: you choose where to share it. See [docs/crash-reports.md](https://github.com/lolitemaultes/Gridline/blob/v0.7.3/docs/crash-reports.md).

- **After a serious error** Gridline closes and offers to restart with a recovery copy of your project. On macOS, Linux and the BSDs that copy is normally saved at the moment of the crash. On Windows it is the last automatic one, from at most about 30 seconds earlier.
- **Lesser errors** (a failed load, export or plugin call) show the same window while Gridline keeps running.
- **If the interface stops answering** for 30 seconds, the window offers to keep waiting or to force a restart, and closes itself if Gridline comes back. Loading, exporting, saving and waking from sleep don't trigger it.
- **Graphics driver resets.** On Windows and Linux, where the driver reports a reset, the window rebuilds its graphics and the project stays open. If that fails or keeps happening, Gridline closes and offers the recovery copy.

### Projects on web and network drives

Projects on Google Drive, Dropbox, OneDrive, iCloud, rclone, gvfs, SMB and NFS now open properly. The file is read once, off the interface, with a progress bar in bytes, the speed, the time left and a Cancel that returns at once.

- **No freezes.** A slow or offline drive no longer freezes Gridline at startup, on the welcome screen, in the open and save dialogs, in the browser, in the missing samples window, when previewing a sound or when quitting.
- **Nothing written behind your back.** Autosave is off for a project on such a drive, and timed backups stay on this computer. Save still writes there.
- **Works offline.** A zipped project on a drive unpacks to a cache on this computer. Opening it again needs no read, and when the drive is offline the last copy opens with a note.

### Zipped projects

- **Clean folders.** Every zipped project, on a local disk too, now unpacks to Gridline's cache instead of beside the archive, and Save asks where to put it. Folders earlier versions unpacked are left alone.
- **Clear cache.** Settings > Files shows the cache's size and clears everything nothing needs, then says what it kept and why. The cache trims itself oldest first, down to 16 GB.
- **Complete archives.** A zipped project now holds every file the project uses. It used to leave some out while reporting nothing missing, such as extra drum pads, Multisampler zones, sound fonts, Plasma wavetables and files used inside a patch. Whatever can't be packed is now named in a notice.
- **Speed and size.** Large archives open far faster, archives over 4 GB work, and packing a large sample no longer needs its size in memory.

### Long work stays in the background

Saving a zipped project, exporting project data files or bones, exporting a clip or sample as WAV, rendering mixer tracks and exporting a project with installed plugins now all run in the background, with a progress bar and Cancel.

- A Cancel or a failure leaves no partial file, and an earlier archive under the same name stays as it was.
- Running out of memory or disk space during an export now reports an error instead of closing Gridline or leaving a cut-off file.
- Cancel stops MP3, Ogg and AAC encoding straight away.
- Exports no longer run at real-time priority, so a long render doesn't take over the rest of the computer.
- A big project with thousands of audio clips uses about half the memory it did, with the same sound.

### Smoother playback on large projects

- **Far fewer dropouts just after opening**, while clips are still rendering in the background: from about 184 to 2 at a 512 sample buffer on a large test project. Clips still rendering no longer overload a block when they start, and background renders run about four times faster on an 8 core machine.
- **Lower CPU.** Channels and effects with nothing to play now rest until sound reaches them. The same project went from about 39% to between 19% and 31% on the CPU meter. Exports still run everything.
- **Soloing no longer freezes the interface.** A solo toggle on a project with thousands of clips took up to 7 seconds and now takes about 50 ms.

### Clips and notes off the grid

A click on a clip or note no longer moves or resizes it. Dragged, it moves by whole grid steps from where it is, one bar at a time with Bar snap for example, and keeps its offset instead of jumping onto the grid. Hold Alt to drag freely. Resizing still lands on the grid.

### Track Receipt calculates shares

Choose the category on the license and the share follows from it and the measured length, in the window, the spreadsheet and the PDF. A share you type replaces the calculated one. Check the figures against your license.

| Used | Category A | Category B | Category C |
| --- | --- | --- | --- |
| Up to 2 seconds | 10% | 5% | 2% |
| Up to 15 seconds | 25% | 15% | 10% |
| Up to 60 seconds | 50% | 30% | 20% |

### Plugin interfaces on Wayland desktops

On systems whose SDL chooses Wayland by itself, such as Arch and CachyOS, or with `SDL_VIDEODRIVER=wayland` set for the session, every plugin's Interface button said its interface could not be attached. Plugin interfaces are X11 windows, so Gridline now runs through XWayland whenever it is available. If an interface still cannot open, the message gives the real reason.

### FL Studio projects

- **Tempo automation.** Projects with a tempo automation clip now play at the right tempo. Gridline reads the range each automation clip stores, for every kind of target, and FL export writes it back.
- **Clips reach their end.** Audio clips no longer stop early when the tempo is automated. On a channel set to Resample, each clip takes the speed that fits it at the tempo where it starts and holds that speed and pitch while it plays, so its audio reaches the clip's end.
- **Sampler levels.** Notes on sampler channels now play at the level the project's settings give them, up to about 6 dB quieter than before at usual channel volumes. The louder level could push drums into the master limiter and distort them.
- **Convolver.** It now sounds as saved: volume, pan and separation curves spread over the whole impulse, so a tail decays at the right time and level.
- **More automation imports:** Velocity Scale, Colour Router, Note Sequencer, all four envelopes of Envelope Mod, and Band Delay's main controls.
- **Patches line up parallel paths** by the latency each plugin reports.
- **Revised engines and ranges** for Sweep Kick, Freq Shifter, Retro Phaser, Multi Delay, the Limiter, Cipher and the Parametric EQ.
- **Pitch bend export.** A bend over another sounding note of the same colour now usually survives, and curves stay within 5 cents for glides of 2 beats and up.

### Tap tempo

A tap tempo button now sits beside the BPM display. Click on every beat: from the second tap the song tempo follows, a whole run of taps is one undo step, and a pause of over 2 seconds starts over. It has a key, Ctrl+Shift+T, and can be linked to a controller from its right-click menu.

### Crest

Crest has a cleaner interface: every knob, button and caption sits on one grid, in the same panels as the other flagship plugins, in both themes.

## Other changes and fixes

- Stretched and pitched audio from files above or below the project's sample rate is much cleaner, and a file now sounds the same whatever its sample rate.
- A low monophonic sound such as a bass line, slowed down in a playlist clip, keeps its waveform and its attacks. Gridline decides this from the audio, per clip.
- The typing keyboard goes by where keys sit, so the notes and the octave and velocity keys stay in place on Dvorak, AZERTY, QWERTZ and other layouts. The hints, the menu and the keys list name the keys as your layout does.
- Platter stays in tune after a scratch with Sync on. It now falls back in phase at once with a short crossfade, where it used to run up to 4% off speed until the beats lined up. In Deck to Deck sync, the following deck no longer chases a deck being scratched.
- Turntable no longer lurches when you scratch across the start of the sample.
- The Convolver no longer stays silent after opening a project when its impulse file was still loading, and Hybrid Synth's wave files and Halftone's image source no longer stay missing in the same case.
- A crash during long mixer edits is fixed. Dragging a send level for a long time could crash Gridline if a block of audio was taking long at that moment.
- Builds with assertions on, such as the AUR source package, start again. Release downloads were not affected.
- Two clips of one pattern back to back no longer lose the new note when a long note ends right where the same note starts again. This covers installed plugins of every format, the MIDI Out channel and exports.
- Audio: adding a built-in instrument or effect during playback no longer risks a dropout on its first block.
- Audio clips from very high sample rate files pitched far up no longer play flat while the clip's final render is being prepared.
- AIFF samples now load, and SFZ maps that use `#include` or `#define` now play correctly.
- Browser moves and renames follow file references spelled with different letter case on Windows and on case-insensitive macOS volumes.
- Files that exist, or aren't files at all, no longer show up as missing samples.
- Piano roll: right-clicking overlapping notes deletes only the top note, and the keyboard shows the Settings accent on hover and the channel's real colour on sounding keys.
- Kerf: a dropped loop no longer stays silent until the next edit on a busy computer.
- Collaborative projects: an SFZ map's samples and a cabinet folder's files now reach every collaborator.
- A Cancel during the last moment of saving a zipped project or exporting project data files now cancels too, where it used to be ignored and leave the file. A Cancel after a sample or clip export has written its file no longer says it was cancelled.
- Piano roll scripts: whole-number knobs such as a ratchet's Repeats now follow a slow drag, and a double-click goes back to the script's own value.

The full list is in [CHANGELOG.md](https://github.com/lolitemaultes/Gridline/blob/v0.7.3/CHANGELOG.md).

## How this was tested, and what wasn't

- **Graphics driver resets are simulated.** The recovery path is tested by forcing the condition. It hasn't been through a real driver reset on real hardware. macOS doesn't report resets, so it has no such recovery.
- **Web and network drives are mostly simulated** in the automated tests, with slow, stalling and vanishing files. One large zipped project was also opened from a real Google Drive folder.
- **Crash reports** are tested with forced crashes on the systems CI runs. If yours comes up wrong, the code it gives you is the thing to send us.
- **Playback figures** come from a test project with no real audio device on a Mac. They weren't repeated on Linux, Windows or a machine with few cores. The first play or seek after opening a large project can still take longer than a block, and opening one can still hold the interface for several seconds.
- **The typing keyboard on other layouts** was tested by simulating Dvorak's key events, not on a real Dvorak system.
- **Plugin interfaces on Wayland** are tested on Arch with Weston in CI, not on every desktop. If yours still fails, the message now says why, so please send it to us.

## Known limits

- **M4A and AAC samples** don't load, so clips using them are silent.
- **Plugin channels in FL Studio projects** may play up to about 5 dB louder than they should, compared with sampler channels. The new sampler levels haven't been checked for them yet.
- **FL Studio tempo automation.** Sampler channels stretched to a time stay fitted at the project tempo, so their notes don't follow the automation.
- **FL Studio parameter audit.** We are still checking every built-in plugin's parameters for FL Studio projects, and some aren't all mapped yet, among them Cipher's enhancer, Pitch Shifter's Music mode, Kerf's per-slice controls, and automation of a single band of Band Delay.
- **Pitch automation on audio channels** adds to the channel's pitch knob instead of replacing it, and moves in whole semitones.
- **A heavy plugin inside a Junction patch** can still cause one short dropout when it is added during playback.
- **Pitch bend export to FL Studio.** A bend is left out, and counted in the export report, when no colour is free or the instrument reads note colours.

- **Windows plugins through yabridge need Wine 9.21 or older for the mouse.** Tested with yabridge 5.1.1 on Ubuntu 24.04, with synthetic input and Carla as a second host. On Wine 9.0 and 9.21 clicks land exactly. On 9.22, 10.20 and 11.21 they land offset by the window's position or get lost, in Carla too.
  - Closing Dexed's interface doesn't return within 30 seconds, in Gridline or in Carla. Gridline now goes on without waiting: the window hides, after 15 seconds the plugin shows as crashed, and quitting ends normally.
  - Closing an interface right after opening it can end the Wine side with an error on Wine 9.0 and 9.21, seen in 9 of 216 runs of a test that does this ten times in a row.
  - Mouse and keyboard under XWayland couldn't be tested automatically. A plugin's interface doesn't open when Gridline runs on the Wayland video driver, which now happens only when there is no XWayland or when `GRIDLINE_VIDEO_DRIVER=wayland` asks for it.

  The full results are in [docs/plugin-window.md](https://github.com/lolitemaultes/Gridline/blob/v0.7.3/docs/plugin-window.md).

## Upgrading from 0.7.2

- Projects open as they are.
- FL Studio projects you imported before keep their tempo, timing, levels and sound until you import them again. Importing again picks up the fixes above.
- Stretched clips and sampler notes from files at another sample rate than the project can sound different in existing projects, as can slowed-down low monophonic clips.
- Shares you already typed in Track Receipt stay as they are. Clear a field to use the calculated share.
- Crest in new instances and FL imports reacts differently while a control moves: moving a delay or attack knob makes a short gap in the sound. Saved projects and presets keep the behaviour they had.
- Collaborative projects: everyone in a session updates to 0.7.3.

## Install

| System | File |
| --- | --- |
| macOS 11 or later (Apple Silicon and Intel) | `Gridline-0.7.3-macos-universal.dmg` |
| Windows 10 / 11, x64 | `Gridline-0.7.3-windows-x64-setup.exe` or `-windows-x64.zip` |
| Windows 10 / 11, ARM64 | `Gridline-0.7.3-windows-arm64-setup.exe` or `-windows-arm64.zip` |
| Linux x86_64 | `.AppImage`, `-linux-amd64.deb`, `-linux-x86_64.rpm` or `-linux-x86_64.tar.gz` |
| Linux aarch64 | `.AppImage`, `-linux-arm64.deb`, `-linux-aarch64.rpm` or `-linux-aarch64.tar.gz` |
| FreeBSD, OpenBSD, NetBSD (x86_64) | `-freebsd-x86_64.tar.gz`, `-openbsd-x86_64.tar.gz`, `-netbsd-x86_64.tar.gz` |
| Source | `Gridline-0.7.3-source.tar.gz` |

- **macOS:** open the `.dmg` and drag Gridline to Applications. The first time, open it with right-click, then Open.
- **Windows:** run the `-setup.exe`. If SmartScreen appears, choose "More info", then "Run anyway".
- **Linux:** use the `.AppImage`, `.deb`, `.rpm` or `.tar.gz`. The `.tar.gz` comes with `install.sh`, which adds Gridline to the desktop menu.
- **BSDs:** use the `.tar.gz` for your system.

The `Gridline-0.7.3-media-tools-<system>.zip` files hold FFmpeg for Import from URL. You do not need to download them: the packages already carry it, and a Gridline built from source fetches the one for its system the first time Import from URL is used, checked against the release's checksums.

## Checksums

Every file's SHA-256 checksum is in `Gridline-0.7.3-SHA256SUMS`. Check a download with `sha256sum -c Gridline-0.7.3-SHA256SUMS --ignore-missing` (Linux, BSD), `shasum -a 256 -c Gridline-0.7.3-SHA256SUMS --ignore-missing` (macOS) or `Get-FileHash <file>` (Windows PowerShell). Gridline's update popup checks the checksum of what it downloads by itself.
