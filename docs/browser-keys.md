# Browsing with the keyboard

Click anywhere in the browser to give it keyboard focus. These keys then work on its list:

| Key | What it does |
| --- | --- |
| Up, Down | Move through the list. A sample you land on previews at once and replaces the one playing. |
| Left | Fold an open folder, or go to the folder above. |
| Right | Unfold a folder, or go to the first thing inside an open one. |
| Enter | On a sample, load it into a new sampler channel, as a double-click does. On a folder, fold or unfold it. On a plugin or preset, the same as a double-click. |
| Page Up, Page Down | Move a page at a time. |
| Home, End | Go to the first or the last row. |
| W, S | Up and Down, while the typing keyboard is off. |

Previews follow the **Sync** button at the bottom of the browser. When you hold a key to run through a long
list, only the sample you stop on plays.

The search box works with the keys too: after a search, click a result and move through the results.
Moving through the list only selects files. Patterns, channels and mixer tracks in the Current project
section take the cursor without changing what is selected in the song; press Enter to select or open one.

The keys only act while the browser has focus and you are not typing in a text field. While the typing
keyboard is on, W and S play notes as usual, and the arrow keys keep browsing.
